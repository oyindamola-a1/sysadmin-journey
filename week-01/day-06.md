**REDIRECTION**

Adding files to linux can be done in a variety of ways. Linux has a few text editors that can be used to add contexts to a file. 

There is a way in linux to quickly add context to a file using a command line feature called Input/Output [I/O] redirection. I/O redirection allows for command to be sent to files, devices and other commands. When it comes to command input and output there are three paths, or "tracks". These paths are called the file descriptors.

**TEXT EDITOR**

The premier text editor for linux and UNIX is a program called "vi". While they are numerous editors available for linux that range from the tiny editorn [nano] to the massive [emas] editor, there are several advantages to tje [vi] editor,

- The [vi] editor is available on every linux distribution in the world. This is not true of any other editor.
- The [vi] editor can be executed both in CLI [Command Line Interface] and a GUI [Graphical User Interface].

There are three modes used in [vi] ; Command Mode, Insert Mode, and Ex-Mode.

**COMMAND MODE MOVEMENT**

Initially, program starts in the command mode, it's used to type commands, such as those used to move around a document, manipulate texts and access to the other two modes.

**COMMAND MODE ACTIONS**

The standard convention for editing context with word processors is use to cut, copy, and paste.

**INSERT MODE**

It's used to add text to the documents.

**EX-MODE**

The [vi] editor was called the [ex] editor, the name [vi] was the abbreviation of the visual command in the [ex] editor which switched the editor to "visual" mode.
