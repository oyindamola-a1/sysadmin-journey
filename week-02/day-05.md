**SECURITY APPLIANCES**

They can be standalone devices like a router or software tools that are run on a network device. They fall into six categories; 

- Routers
- Firewalls
- Intrusion Prevention Systems [IPS]
- Virtual Private Network [VPS]
- Antimalware or Antivirus
- Other security devices like web and email security appliances, decrypyion devices etc.

**FIREWALLS**

A firewall is designed to control or filter whivh communications are allowed in and which are allowed out of a device or network.

**TYPES OF FIREWALL**
- Network layer firewall
- Transport layer firewall
- Application layer firewall
- Context aware layer firewall
- Proxy server
- Reverse proxy server
- Network address translation [NAT] firewall
- Host-based firewall

**PORT SCANNING**

Port scanning is a process of probing a computer, server or other network host for open ports.

**INTRUSION DETECTION AND PREVENTION SYSTEMS**

Intrusion Detection System [IDS] and Intrusion Prevention Systems [IPSs] are security measures deployed on a network to detect and prevent malicious activities.
