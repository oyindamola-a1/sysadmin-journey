**ON PATHS ATTACKERS**

It's a type of attack referred to as Man-in-the-Middle or Man-in-the-Mobile, it modifies communication between two devices, such as web browser and a web server, either to collect information or to impersonate one of the devices.
- A Man-in-the-Middle attack happens when a cybercriminal takes control of a desire without the user knowledge.
- M Man-in-the-Mobile attack used to take control over a user's mobile device.

**SEO [SEARCH ENGINE OPTIMIZATION] POISONING**

It's about improving an organization's website so that it gains greater visibility in search engine results.

**CRYPTOCURRENCY**

It's a digital money that can be used to buy goods and services using strong encryption techniques to secure these online transaction.

**CRYPTOJACKING**

It's an emergency threat that hides on a user's computer, mobile phones, tablets, laptops or server using that machine's resources to 'mine' cryptocurrencies without the user's consent or knowledge.
